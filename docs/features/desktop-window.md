# 功能 README：桌面窗口与系统托盘

## 功能目标

`src/main/main.cjs` 创建 430 × 740 的无边框透明窗口，将它放在主显示器右下角并默认保持置顶。窗口不显示在任务栏，隐藏后继续驻留系统托盘。

## 行为

- 拖动待办对话框标题栏移动桌宠。
- 关闭窗口等同于隐藏，不会丢失待办数据。
- 单击托盘图标切换显示和隐藏。
- 托盘菜单可以切换置顶、重置到右下角或完全退出。
- 窗口位置与置顶设置保存到 Electron `userData/window-settings.json`。
- 透明空白位置使用 `setIgnoreMouseEvents(..., { forward: true })` 尽量让鼠标事件穿透到下方应用；待办框和角色区域保持可交互。

## 安全边界

渲染进程启用了 `contextIsolation` 和沙箱，关闭 Node 集成。只有 `src/main/preload.cjs` 暴露的有限窗口操作可以通过 IPC 调用。本地资源由只允许读取应用目录的 `remielle://app/` 协议提供，外部导航与新窗口均被阻止。

## 验证

1. 运行 `npm start`，确认窗口透明、无标题栏且位于右下角。
2. 拖动对话框标题，重启后确认位置恢复。
3. 点击 `–`，从托盘图标恢复。
4. 在窗口透明边缘点击下方应用，确认事件可以穿透。
