# 功能 README：待办事项对话框

## 功能目标

桌宠头顶显示粉色到薰衣草紫的渐变对话框，支持快速记录、完成、恢复、删除和批量清理待办。

## 数据字段

每条待办包含：

- `id`：本机生成的唯一标识；
- `text`：去除首尾空格后的文本，最多 80 个字符；
- `completed`：完成状态；
- `createdAt`：创建时间戳。

最新事项排在最前。列表最多恢复 100 条有效记录，损坏或格式不正确的本地数据会安全回退为空清单。

## 动画反馈

新增待办、首次标记完成时播放 `c` 高兴动画。删除和取消完成不会强行打断当前角色状态。创作模式中触发高兴动画后会自动回到 `d`。

## 本地存储

数据通过浏览器 `localStorage` 保存，键名为 `remielle.todo-items.v1`。应用不会上传待办，也不需要账号。卸载应用时是否清除数据取决于 Windows 是否保留 Electron 用户数据目录。

## 验证

1. 新增三条待办，确认最新一条位于顶部。
2. 完成、取消完成并删除事项，确认计数正确。
3. 重启应用，确认列表与完成状态仍在。
4. 完成若干事项后点击“清除已完成”。
