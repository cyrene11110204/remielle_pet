# 功能 README：动画轮换与趣味反馈

## 新增待办后的轮换

每次确认一条新待办，状态机在两套反馈之间轮换：

1. a_win 拿笔准备 → d 单次创作 → 返回基础动作。
2. b 抬头思考 → 返回基础动作。

轮换只存在于本次运行期间，不写入待办数据。这样连续记录多条事项时不会反复观看同一反馈。

输入框获得焦点时播放 b 思考动作，离开输入框后回到当前基础动作。输入期间出现的 ？、✦、♡、💭、✎ 是独立 HTML 装饰，不占用 Spine 轨道，也不会抢占主题动画。

## 完成待办后的庆祝

首次把待办标记为完成时：

1. Spine 轨道 0 播放 d_win。
2. 接着播放 c。
3. 最后回到 a、b 或 d 基础状态。
4. 同时在独立图层生成 42 片粉色、紫色、黄色和白色彩纸。

彩纸只使用 CSS 动画，不能点击，不改变待办布局。系统开启“减少动态效果”时，彩纸和输入装饰自动隐藏。

## 状态安全

状态机使用递增令牌取消过期回调。快速添加、完成或手动开始创作时，旧动画完成事件不会覆盖新状态。
