# 功能 README：Spine 动画状态机

## 资源与版本

骨骼数据由 Spine `4.2.43` 导出，运行时固定为 `@esotericsoftware/spine-player@4.2.120`。主版本 `4.2` 必须一致。应用使用本地运行库，不从 CDN 加载。

## 动画分配

| 动画 | 语义 | 触发方式 |
| --- | --- | --- |
| `a` | 思考 | 默认循环、鼠标离开后恢复 |
| `a_win` | 思考后拿笔准备 | 点击“开始创作”后单次播放 |
| `b` | 抬头思考 | 鼠标进入角色区域后循环 |
| `c` | 看着本子高兴 | 新增/完成待办或创作完成时单次播放 |
| `d` | 开始创作 | `a_win` 完成后循环 |
| `d_win` | 创作完成后高兴 | 点击“完成创作”后单次播放 |
| `e` | 可爱又可怜地抬头 | 在角色区域持续悬停 3.6 秒后循环 |
| `light` | 开灯 | 点击 `☼` 后在轨道 1 单次播放 |

## 状态流

```text
默认 a ──悬停──> b ──3.6 秒──> e
   ^              │
   └──鼠标离开────┘

a/b/e ──开始创作──> a_win ──完成──> d（循环）
d ──完成创作──> d_win ──完成──> c ──完成──> a 或 b
```

`src/shared/animation-state-machine.js` 只处理动作决策；`src/renderer/renderer.js` 中的驱动器负责调用 Spine。过时的单次动画回调会被令牌机制丢弃，避免快速点击时旧回调覆盖新状态。

## 失败回退

若 WebGL、JSON、atlas 或贴图加载失败，界面隐藏 Spine 播放器并显示 `spine/read.png`，待办功能仍然可用。

## 验证

- 运行 `npm test` 检查悬停、创作序列、高兴反馈和开灯轨道。
- 运行 `npm run check` 额外检查 Spine 版本、全部动画名和贴图文件。
