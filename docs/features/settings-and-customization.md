# 功能 README：设置与界面精简

## 功能目标

release2 在待办标题右侧增加齿轮按钮。用户可调整宠物显示比例、开关视线跟随，并决定悬浮操作栏中保留哪些按钮。

## 可配置项目

- 宠物大小：70% 到 130%，每次调整 5%。
- 备忘框大小：70% 到 130%，与宠物大小独立调整；默认 100% 保持 v1 的对话框尺寸。
- 紧凑间距：界面根据宠物和备忘框的缩放比例计算固定纵向偏移，使两者保持靠近；窗口拖动不会改变这个值。
- 视线跟随鼠标：默认开启。
- 创作按钮：默认显示。
- 灯光按钮：默认显示。
- 隐藏按钮：默认显示。
- 恢复默认设置：一次恢复上述默认值，包括两个独立缩放值。

设置保存在 localStorage 的 remielle.preferences.v2 中，重启应用后继续生效。损坏、越界或缺失的数据会由 src/shared/preferences-store.js 自动修正。

## 清爽显示逻辑

悬浮操作栏默认完全透明且不接收鼠标事件。只有鼠标进入宠物区域或按钮获得键盘焦点时才显示，离开后恢复为只显示宠物和待办框。用户取消全部三个按钮后，操作栏不会创建可见空壳。

如果用户在创作或开灯期间关闭对应按钮，当前状态会先安全结束，再隐藏按钮，避免留下无法关闭的状态。

## 验证

- tests/preferences-store.test.cjs 检查默认值、两个缩放值的持久化与边界，以及损坏数据恢复。
- scripts/validate-release2.mjs 检查设置模块、v2 页面和构建入口。
