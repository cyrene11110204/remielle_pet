# 功能 README：交互、数据与无障碍

## 操作反馈

界面通过角色状态文字和短暂提示条反馈添加、完成、进入创作、开灯等操作。交互按钮均提供中文标签、键盘焦点样式及 `aria-pressed` 状态。

## 窗口交互区域

- 对话框和角色舞台标记为 `interactive-zone`，可以点击和悬停。
- 窗口其余透明部分动态切换为鼠标穿透，减少挡住桌面应用的情况。
- Spine Player 自身交互被关闭，角色动画由状态机统一控制。
- 右键任一可交互区域打开托盘菜单。

## 数据边界

- 待办：渲染进程 `localStorage`。
- 窗口坐标、置顶：主进程 Electron `userData` 目录。
- 不执行网络同步、遥测或第三方账号登录。

## 减少动态效果

当 Windows/浏览器环境启用“减少动态效果”时，CSS 过渡会缩短。Spine 动画仍会播放，因为它承载角色功能状态；如果后续需要完全静态模式，可以在状态机驱动层统一暂停。
